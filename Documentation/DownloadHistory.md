This page records the final GitHub download count for Roam Control IPA assets when they are retired.

GitHub's download count represents downloads of the release asset, not unique users. Repeated downloads of the same IPA are included.

Public IPA distribution ended on 24 November 2026 with the transition to the Apple App Store. GitHub release pages remain available as historical documentation.

## End of public IPA distribution

**Total recorded GitHub IPA downloads: 10,294**

These figures cover the six recorded releases and do not represent unique users or a complete count of every early beta download.

App Store downloads are not included in these historical figures.

> [!IMPORTANT]
> **Distribution update - 25 November 2026**
>
> Roam Control was released on the App Store on 24 November 2026. Following a subsequent re-evaluation by Apple, it is currently unavailable for new downloads.
>
> Apple has been contacted and clarification is pending.
>
> **Do not delete or uninstall your existing Roam Control installation.** Migration to the App Store is currently suspended, and public IPA downloads are unavailable.
>
> Existing users are encouraged to create a backup through **Settings > Backup & Restore**, where supported, and save it safely outside the app.
>
> Roam Control has not been discontinued. Further updates regarding availability will be published here.
