# Roam Control Download History

This page records the final GitHub download count for Roam Control IPA assets when they are retired.

GitHub's download count represents downloads of the release asset, not unique users. Repeated downloads of the same IPA are included.

Public IPA distribution ended on 24 November 2026 with the transition to the Apple App Store. GitHub release pages remain available as historical documentation.

## End of public IPA distribution

**Total recorded GitHub IPA downloads: 10,293**

These figures cover the six recorded releases and do not represent unique users or a complete count of every early beta download.

App Store downloads are not included in these historical figures.

> [!IMPORTANT]
> **Roam Control is now available on the App Store.**
>
> Public IPA distribution has ended.
>
> Existing sideloaded users must create a backup in **Settings > Backup & Restore**, save it safely outside the app, confirm App Store availability in their region and use **Stop & Restore** before deleting the old installation.
>
> Then [Download Roam Control on the App Store](https://apps.apple.com/app/roam-control/id6838265385), restore the backup and pair the device again.
>
> Backup & Restore is available from version 0.9.4 onwards. Users of earlier versions should contact support before deleting their existing installation if they need to preserve data.
