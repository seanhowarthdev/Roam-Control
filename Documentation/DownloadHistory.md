# Roam Control Download History

This page records the final GitHub download count for Roam Control IPA assets when they are retired.

GitHub's download count represents downloads of the release asset, not unique users. Repeated downloads of the same IPA are included.

Public IPA distribution temporarily ended on 24 November 2026 with the transition to the Apple App Store. Build 105 was restored on 25 November 2026. All earlier IPA assets remain retired.

## Historical downloads before restoration

**Total recorded GitHub IPA downloads before restoration: 10,294**

These figures cover the six recorded releases and do not represent unique users or a complete count of every early beta download.

App Store downloads are not included in these historical figures.

## Build 105 restoration

On 25 November 2026, the original [Build 105 IPA](https://github.com/seanhowarthdev/Roam-Control/releases/tag/v0.9.9) was restored.

The original asset recorded 4,300 downloads before retirement. The restored asset has a separate GitHub download counter. Downloads recorded after restoration are not included in the historical totals above.

> [!IMPORTANT]
> **Distribution update - 25 November 2026**
>
> Roam Control was released on the App Store on 24 November 2026. Following a subsequent re-evaluation by Apple, App Store and TestFlight availability have been disabled.
>
> The previously released Roam Control 0.9.9 (Build 105) IPA is available again for independent sideloading through [GitHub Releases](https://github.com/seanhowarthdev/Roam-Control/releases/tag/v0.9.9). This is an existing release, not a new update.
>
> Apple has been contacted and clarification is pending.
>
> **Do not unnecessarily delete or uninstall your existing Roam Control installation.** Migration to the App Store remains suspended. Build 105 is available for independent sideloading.
>
> Existing users are encouraged to create a backup through **Settings > Backup & Restore**, where supported, and save it safely outside the app.
>
> Roam Control has not been discontinued. Further updates regarding availability will be published here.
